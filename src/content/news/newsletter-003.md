              <h2 style="margin: 0 0 15px 0; font-size: 24px; line-height: 1.4; color: #ffffff;">‘AI 잘 쓰는 것’도 졸업 역량일까? 교수진에게 물었다</h2>
              <p style="margin: 0 0 25px 0; font-size: 16px; color: #aaaaaa; line-height: 1.6;">지난 6월 소개된 역량기반 졸업요건 개편 이후, 학우들 사이에서는 기존 성취기반평가와 새 졸업요건이 어떻게 연결되는지, 대학이 말하는 AI 역량은 무엇인지에 대한 궁금증이 이어졌다. 본지는 역량평가 TF 교수진을 만나 제도의 취지와 평가 기준, 준비 방향을 물었다.<br><br>성취기반평가가 개별 교과목의 성취 기준 도달 여부를 확인한다면, 역량기반 졸업요건은 졸업 시점에 전공자로서 충분한 수준에 이르렀는지를 종합적으로 살핀다. 김 교수는 두 제도를 ‘하나의 선’이라고 설명했고, 황 학장은 제도를 벌집에, 평가에 관한 고민을 꿀에 비유했다.<br><br>대학이 평가하려는 AI 역량은 AI에 대한 이해, AI를 활용한 문제 해결, 환각과 오류를 가려내는 산출물 검증, 제한된 자원으로 정확한 결과를 얻는 효율적 활용으로 나뉜다. 다만 구체적인 정의와 평가 지표는 아직 논의 중이며, 외부 평가를 활용하는 것은 객관성과 공신력을 확보하기 위해서다. 교수진은 AI역량평가를 단기간에 대비할 시험으로 보지 말고 교육과정 속에서 꾸준히 역량을 기르는 것이 중요하다고 강조했다. 황 학장은 학생들이 교육과정을 잘 따라오면 자연스럽게 평가에서도 역량을 보여줄 수 있게 하는 것이 궁극적인 목표라고 말했다.</p>

              <h2 style="margin: 0 0 15px 0; font-size: 24px; line-height: 1.4; color: #ffffff;">“스펙 쌓기 전에 이유부터 만드세요”… 동문 선배들이 털어놓은 취업 현실</h2>
              <p style="margin: 0 0 25px 0; font-size: 16px; color: #aaaaaa; line-height: 1.6;">지난 8월 29일 오후 3시부터 6시까지 미래관 자율주행스튜디오에서 동문 패널톡 ‘선배들의 취업 &amp; 커리어’가 열렸다. 현업에서 활약 중인 동문 8명이 학교를 찾아 후배들에게 취업 준비 과정과 현업의 생생한 이야기를 전했다.<br><br>행사는 취업 준비 과정, 현업 분위기와 트렌드, 90분간의 릴레이 멘토링 등 세 개 세션으로 이어졌다. 학생들은 네 개 조를 돌며 클라우드·금융, 차량 소프트웨어, AI·보안, 창업 분야 선배들과 대화했고, 사전에 모은 22개의 질문이 논의의 바탕이 됐다. AI 도구를 실무에 어디까지 활용하는지, AI 시대에 신입에게 기대하는 역량은 무엇인지도 주요 화두였다.<br><br>김선우 동문은 후배들의 관심사가 생각보다 다양하고 현업 트렌드에도 민감하다는 점에 놀랐다고 말했다. 그는 “가장 중요한 것은 이유를 만드는 것”이라며, 4년간의 활동에 목적을 담고 지원하는 회사에 맞춰 이야기를 풀어내는 신입이 환영받는다고 조언했다. 또 장황한 포트폴리오보다 회사에 최적화된 신입이라는 점을 어필하는 편이 좋다고 덧붙였다.</p>

              <h2 style="margin: 0 0 15px 0; font-size: 24px; line-height: 1.4; color: #ffffff;">국민대 소프트웨어융합대학, 11월 10일 ‘2026 CAREER WEEK’ 개막</h2>
              <p style="margin: 0 0 25px 0; font-size: 16px; color: #aaaaaa; line-height: 1.6;">국민대학교 소프트웨어융합대학이 11월 10일부터 13일까지 나흘간 ‘2026 CAREER WEEK’를 연다. 졸업생과의 만남에서 진로 설계, 채용 상담, 프로젝트 성과 공유까지 학생의 성장 과정을 하루씩 나눠 담았으며, 행사는 미래관 자율주행스튜디오 429호를 중심으로 열린다.<br><br>10일 Alumni Day는 GREAT Program 소감발표회와 졸업생 간담회, 11일 Career Design Day는 커리어 특강과 올해 처음 마련한 진학·연구실 설명회로 꾸며진다. 12일 Job Fair Day에는 기업 설명회와 채용 상담, 현직자 멘토링이 이어지고, 13일 Challenge &amp; Future Vision Day에는 올해 처음 선보이는 AI톤과 유레카 프로젝트 전시·시상이 열린다. AI톤은 학년이 섞인 팀이 하루 만에 AI 서비스를 만드는 프로그램으로, 수상 팀에는 우수학생장학금이 지급된다.<br><br>참여 확인은 입장과 퇴장 때 각각 찍는 QR 코드로 하며, 일부 전공 수업은 행사 참여로 대체된다. 스탬프 3개를 모으면 경품 응모권 1장을 받고, 경품으로는 닌텐도 스위치 2와 보스 헤드셋, 백화점 상품권이 준비돼 있다. 경품 추첨은 13일 AI톤 시상식 직후 진행한다.</p>

              <h2 style="margin: 0 0 15px 0; font-size: 24px; line-height: 1.4; color: #ffffff;">고등학생 70명, 2시간의 승부 · 제11회 국민대학교 알고리즘 대회</h2>
              <p style="margin: 0 0 25px 0; font-size: 16px; color: #aaaaaa; line-height: 1.6;">지난 7월 23일 미래관 고사장에서 제11회 국민대학교 알고리즘 대회가 열렸다. 소프트웨어융합대학과 SW중심대학사업단이 주관하고 ㈜그렙이 후원한 이 대회에는 고등학교 재학생과 졸업생 80명이 접수해 70명이 실제로 응시했다. 소프트웨어에 대한 열정과 창의성, 문제 해결 역량을 갖춘 학생을 발굴해 우수한 인재로 키운다는 취지로, 올해 11회를 맞았다.<br><br>대회는 오후 2시부터 4시까지 2시간 동안 대면 시험으로 진행됐다. 참가자들은 학교가 제공한 노트북에서 C++, Java, Python 3 중 하나를 골라 문제를 풀었고, 기본 알고리즘을 얼마나 정확하고 효율적으로 응용하는지, 여러 알고리즘을 엮어 해결할 수 있는지를 평가받았다. 채점과 검증은 교내외 대학교수로 구성된 평가 검증 위원회가 맡았다.<br><br>9월 5일 미래관 445호 코딩 스튜디오에서 열린 시상식에서는 경주고 박주형 학생이 대상을 받았다. 금상은 이지후, 은상은 강산(이상 한국디지털미디어고) 학생이, 동상은 이동현(과천중앙고)·임재욱(의정부고) 학생이 수상했고, 수상자 전원에게 국민대학교 총장 명의의 상장이 주어졌다.</p>
